How the test works

For each player, three algorithms estimate next-game rushing or receiving yards using only earlier observed games: all-prior mean, last-three mean, and previous-game value. Each is scored on exactly the same held-out observations. It compares that estimate with the actual result. Mean absolute error (MAE) measures the average number of yards the estimate missed by; lower is better.

This is a limited ESPN sample and cannot establish sportsbook edge, touchdown probabilities, or reliable performance across a full NFL season. The smallest MAE here does not establish a winning strategy: model selection on the same observations can overfit. More historical coverage, an untouched future test period, and stronger features are needed.
